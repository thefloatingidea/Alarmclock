## 1. Concept

An alarm clock app built with **Flutter + Flame**. The home screen shows a
floating **isometric island** with a central **clock tower** that displays the real time.

- Wake up on time (stop the alarm within 15 s) → the island grows by one "day"
  (more land, trees, houses, landmarks).
- Oversleep → a **dragon** wakes up and burns the city over 60 s.
- In-game currency: **Shields** (dome that absorbs 2 missed alarms) and
  **Water buckets** (20 restore a burned city with rain).
- Villagers wander and show speech bubbles that react to what is happening.
- Everything is drawn in code with Canvas (no image assets). The only asset is
  `assets/audio/alarm.wav`, generated by a Python script (2 s beep loop, free to use).

Target: Android/iOS (portrait first), also works on web/desktop.

## 4. Core rules (single source of truth)

### 4.1 Alarm timeline (`destruction.dart`, values from `MonsterSpec`)
| Elapsed since ring | State |
|---|---|
| `0 … wake-5` | Monster asleep (Zzz) |
| `wake-5 … wake` (10–15 s) | **Stirring** (shake, "!" , eye opens) |
| `wake` = **15 s** | Monster wakes and flies to the island |
| `wake … wake+burnFor` (15–75 s) | Burning; `fraction(e)` goes 0 → 1 over **60 s** |
| fraction 0–0.85 | Buildings ignite one by one (`igniteAt(order, n)`), each burns 8 s + 1.5 s collapse |
| fraction 0.85–1.0 | Island crumbles (`crumble(e)`), tiles fall from edges inward |
| `total` = 75 s | City gone |

Constants in `Destruction`: `stirWindow=5`, `buildingBurn=8`, `collapseDuration=1.5`,
`freeRestoreLimit=0.5`. `Destruction.spec` = active monster (default `Monsters.dragon`).

### 4.2 Outcomes (`AlarmEngine.stop()` / `_timeout()`)
| Situation | Result (VillageState method) |
|---|---|
| Stopped before 15 s | `wakeOnTime()` → streak+1, level+1, +5 buckets, +1 shield every 7-day streak |
| Late, shield active | `shieldBlocked()` → 1 shield charge used, **streak kept**, no damage |
| Stopped with burned < 50 % | `partialDamage(collapsed, fraction)` → ruins saved, streak=0, `damagePct` set → **free restore** overlay → `restoreFree()` (rain) |
| Stopped with burned ≥ 50 % | `engine.finishing = true`, audio stops, time runs at 10× until 75 s → `markDestroyed()` |
| Never stopped (75 s) | `markDestroyed()` (or `shieldBlocked()` if shield) |
| City destroyed | Overlay: `restoreWithWater()` (−20 buckets, rain, keeps level) **or** `startOver()` (level 0) |
| Snooze (5 min) | `applySnooze()`: with shield → no loss; without → collapsed ruins + one more building ruined |

Note (design decision, changeable): free restore keeps the **level** but resets the **streak**.

### 4.3 Island growth (`layout.dart`)
- Grid 16×16, centre 8. Tower occupies `towerRect = (6.5,6.5,3,3)`.
- `islandHalf(level) = min(8, 3 + level ~/ 3)` → 6×6 at day 0, full 16×16 at day 15.
- Every `Item` has an unlock `day`; it appears when `level >= day` and it fits on the island
  (`minDayForExt`). `maxLevel = 60`.
- Hand-placed schedule (houses days 2,4,6,8,11,13,17,19,22,24,26,28; well 5; field 7/23;
  river 9; windmill 10; barn+sheep pen 12; pond 14; mountains 15/16/18; lighthouse 20;
  church+bridge 21; market 25; balloon 29; gold tower 30). Then 60 trees + 45 decor
  generated with `Random(7)` spread over days 1–40 (deterministic).
- `activeBuildingIds(level, ruined)` = burnable buildings (house/barn/church/market/windmill).
- Item ids = index in `layout` list (used for `ruined` set and `buildings` map).

### 4.4 Currency (`VillageState` constants)
| Constant | Value |
|---|---|
| `restoreCost` | 20 buckets |
| `missesPerShield` | 2 |
| `bucketsPerWake` | 5 |
| `shieldEveryDays` | 7 |
| New player wallet | 1 shield, 10 buckets |

Shield flow: `shields` (inventory) → `activateShield()` → `shieldCharges += 2`.
`shieldActive = shieldCharges > 0`. Dome is visible while active.

Shop packs (`shop_sheet.dart` → `packs`):

## 5. Key classes & APIs

### 5.1 `Alarm` (alarm.dart)
Fields: `id, hour, minute, label, enabled, days(Set<int> 1=Mon..7=Sun; empty=once)`.
Methods: `copyWith`, `firesAt(now)`, `nextFire(now)`, `daysLabel`, `toJson/fromJson`.
Helpers: `hourMinute(h,m)` → "7:00", `amPm(h)`.

### 5.2 `AlarmStore` (ChangeNotifier) – prefs key `alarms_v1`
`alarms`, `newId()`, `upsert`, `remove`, `toggle`, `next(now)` → `(Alarm, DateTime)?`.
Seeds Work 7:00 weekdays (on) and Gym 8:30 weekends (off).

### 5.3 `AlarmEngine` (ChangeNotifier)
- `Timer.periodic(250 ms)` → `_tick()`: fires matching alarms once per minute (`_lastFiredKey`), handles snooze, timeout.
- State: `ringing`, `preview`, `finishing`, `snoozeUntil`, `elapsed` (segment-based so speed can change via `_setScale`).
- `previewRing()` → 4× speed, nothing saved. `stop()`, `snooze()`.
- Audio: `FlameAudio.loop('alarm.wav')`, guarded by `_session` counter.
- Only runs while app is open (no background scheduling yet).

### 5.4 `VillageState` (ChangeNotifier) – prefs key `village_v3`
Persisted: `level, streak, best, damage(damagePct), shields, buckets, charges(shieldCharges), destroyed, ruined`.
Transient: `rainSerial` (increment → game plays 4.5 s rain), `_message` (snackbar via `takeMessage()`).
Methods: `wakeOnTime, shieldBlocked, partialDamage, restoreFree, markDestroyed,
restoreWithWater, startOver, applySnooze, activateShield, addCurrency, simulateOnTimeWake, simulate(days)`.
Getters: `shieldActive, canRestore, activeBuildings`.

### 5.5 `VillageGame` (FlameGame<VillageWorld> with ScaleDetector, ScrollDetector)
Important getters used by components:
`animTime, wallNow, hourOfDay, ringing, elapsed, shieldUp, stirring, dragonAwake,
attacking (= awake && !shield), burnFraction, scorch, crumble, nightness, gold (level>=30),
villagerCount, digitColor, halfShown (animated island size), perch (monster rock pos),
domeCenter/domeRx/domeH, rainT, shieldHit, breathTarget, content (world rect), monster,
buildings (Map<int,Building>), villagers, monsterLine/monsterLineT`.
Functions: `tileRise, tileDrop, dropAt, itemReady(item), buildingStatus(id)`, `resetView()`.
- Camera: auto-fit to content (portrait zooms 1.0–1.4× closer as the island grows);
  pinch/drag/mouse-wheel set `_manual=true`; resets on level change or `resetView()`.
- Zoom limits: 0.55× – 4.5× of fit zoom. Camera shake while stirring/attacking.
- Sky: time-of-day gradient keys, stars + moon at night, drifting clouds, red tint while attacking, grey during rain.
- Breath target: building that just ignited; random ground when none; shield dome top when shielded.
- Talk timer: every 6–11 s (1.4–2.4 s while ringing) picks a villager via `Talk.pick`; monster taunt 35 % chance while awake.

Note: names `time`/`now` are avoided (clash with FlameGame); use `animTime` / `wallNow`.

### 5.6 Rendering conventions
- Isometric: `Iso.p(gx, gy, z)` → `Offset((gx-gy)*32, (gx+gy)*16 - z)`. Tile = 64×32 px.
- Wall-local drawing: `canvas.transform(Iso.leftWall(origin))` (front-left face, +gy side),
  `Iso.rightWall` (front-right face, +gx side), `Iso.ground` (flat on grass).
- Depth: `IsoObject.priority = (x+w+y+d)*100`. Layers: Island −100000, Ground −90000,
  balloon 1.5M, shield dome 1.9M, monster 2.0M, breath 2.1M, beam 1.0M, rain 3.0M, speech 4.0M.
- Pop-in: `appear` 0→1 with `easeOutBack` scale.
- Crumble: everything translates down by `dropAt(x,y)`; hidden if > 500–700 px.
- Helpers in iso.dart: `poly, line, darken, lighten, isoBox, isoPyramid, isoGableRoof, groundShadow, drawDigit (7-segment), drawFlames, Puffs (smoke)`.

### 5.7 Monster template
- `MonsterSpec { id, name, wakeAfter=15, burnFor=60, breathColors[3], scale=1.7, unlockDay, taunts }`.
- `abstract class Monster extends Component`: handles `fly` (0 rock → 1 hover), `pos`, `facingLeft`,
  hover higher (z 240) when shield is up, `drawPerch` (burnt nest with bones).
  Subclass must implement: `Offset get mouthLocal`, `drawSleeping(c,t,{stirring})`, `drawAwake(c,t,{breathing})`.
  Local coords: origin at feet, facing right; base class applies scale and mirroring.
- `EmberDragon`: crimson body `0xFF7A1C1C`, dark `0xFF3A0C0E`, belly `0xFFC98A4A`, bone `0xFFE8DCC0`,
  membrane `0xFF5A1416`; horns, frill, glowing slit eyes, fangs, opening jaw with mouth glow,
  bat wings with finger bones, spade tail, back spikes, scales, nostril smoke, embers.
- Add a monster: new spec in `Monsters` → subclass → register in `VillageWorld.createMonster` → set `Destruction.spec`.

### 5.8 Villagers & chatter
- 10 `Villager`s; visible count = `1 + min(9, level ~/ 3)` (0 when destroyed).
- Index 0 = **clock-keeper** (purple robe, beard, pointed hat, lantern) pacing in front of the tower; present from day 0.
- Others walk the main road (gy≈10.2–10.8) or the avenue (gx≈7.7–8.3); range widens with level; run when attacking.
- `say(text)` sets bubble for ~3.5 s + length. `SpeechLayer` draws white bubbles (villagers) and a dark red bubble for monster taunts.
- `Talk.pick(game, rnd, keeper:)` categories: finishing, shield holding, attack, stirring, ringing, damaged,
  keeper on day 0, streak ≥3 / streak 0, shield status, time of day (morning/afternoon/evening/night), level ≥10, level ≥30.

### 5.9 Effects
- `ShieldDome`: translucent cyan dome with shimmering rings, flashes orange on breath hit (`shieldHit`), crystal glow on spire.
- `RainLayer`: clouds + 240 drops + splashes for `rainT` (4.5 s) after any restore.
- `LighthouseBeam`: from lighthouse (day 20+) or red warning beam from tower spire while ringing.
- Scorch: tiles/trees/fields darken progressively with `scorch`, embers on burnt ground, trees catch fire.

## 6. UI (Flutter widgets)

- **HomeScreen** stack: `GameWidget` → top row (`_StatusBar` + re-centre button) → bottom `AlarmPanel`
  → state overlay (Ringing > Destroyed > Damaged).
- **_StatusBar** (tap = shop): 🔥 streak · Day N · 🛡 shields (+charges on) · 💧 buckets · (+).
- **AlarmPanel** (collapsible header with "Next in Xh Ym"): buttons Shop 🏪, Test 🧪, Preview ⚡, Add ⏰; alarm rows with switch; tap row = edit.
- **RingingOverlay**: label, current time, stage text, meter:
  - before wake: green "Dragon wakes in Ns" countdown bar;
  - shield: "Shield holding – N misses left";
  - attacking: "City burned: X%" bar with white 50 % marker and "FREE REBUILD" / "COSTS 20 BUCKETS".
  - `HoldToStopButton` (hold 1.4 s), Snooze button. Hidden while `finishing`.
- **_DamagedOverlay**: "X% of your city burned" + "Restore for free".
- **_DestroyedOverlay**: buckets owned, "Rain 20 buckets & restore" (or "Get water buckets" → shop), "Start over from day 0".
- **Shop**: wallet cards, shield activation card, pack tiles with badges, "Earn for free / How they work" info.
- **Test tools**: day slider 0–60, presets 0/3/7/15/30/60, +1 day, +2 shields +50 buckets.
